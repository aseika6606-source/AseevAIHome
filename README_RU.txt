ASEEV AI HOME — Android-проект

Проект содержит цифровой дом с комнатами: Игровая, Идеи, Мастерская и Библиотека.
Заметки сохраняются локально в хранилище приложения. Кнопка ChatGPT открывает сайт ChatGPT.
Приложение не управляет телефоном и не получает доступ к контактам, камере, микрофону или файлам.

Сборка APK через GitHub Actions (можно начать с телефона):
1. Создай репозиторий на GitHub.
2. Загрузи в него содержимое этой папки (файлы проекта должны лежать в корне репозитория).
3. Открой вкладку Actions и выбери workflow “Build Android APK”.
4. Нажми “Run workflow” и дождись зелёного статуса.
5. Открой завершившийся запуск и скачай Artifact “Aseev-AI-Home-debug-apk”.
6. Распакуй скачанный artifact — внутри будет app-debug.apk.
7. Перенеси APK на Android и установи. Android может попросить разрешить установку из выбранного источника.

Требования проекта: Android Gradle Plugin 8.7.3, Kotlin 2.0.21, JDK 17, Android API 35, minSdk 23.
Важно: это debug APK для личной установки, не публикационная подписанная сборка.
